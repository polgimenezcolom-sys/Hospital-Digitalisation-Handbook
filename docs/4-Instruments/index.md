# The Instruments

The things you actually fill in. Nine of them, ordered by when you use them.

An instrument is **done when it is completed**, not when it has been read. Each one has a code short
enough to say out loud — *"has anyone finished D-1 for the pharmacy?"* is a question a team can ask
each other in a corridor.

## Before you go

| | Instrument | Produces |
|---|---|---|
| **[B-1](B1-Readiness.md)** | Readiness assessment | A score for the gap between what the system assumes and what the hospital is |
| **[B-2](B2-Level-Decision.md)** | Level decision | Which of the four levels this deployment is, or a decision not to deploy |
| **[B-3](B3-Mandate.md)** | Mandate and ownership | Named stakeholders and a written agreement |

## While you are there

| | Instrument | Produces |
|---|---|---|
| **[D-1](D1-Data-Capture.md)** | Field data capture | The record you cannot reconstruct from home |
| **[D-2](D2-Infrastructure-Audit.md)** | Infrastructure audit | Power, network, space, existing IT, environment |
| **[D-3](D3-Workflow-Mapping.md)** | Workflow mapping | The patient journey as it actually is |
| **[D-4](D4-Exit-Gates.md)** | Phase exit gates | A defensible answer to "is this phase done?" |
