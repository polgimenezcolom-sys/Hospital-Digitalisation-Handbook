# Packing list

What two deployments' worth of teams wish they had brought. Adapt; then put your own additions back
into this page.

## Measurement

- [ ] Multimeter (voltage over 24 h is a day-one task)
- [ ] Plug-in power meter — real draw, not nameplate
- [ ] A phone with the [D-1 KoBoToolbox form](../4-Instruments/D1-Data-Capture.md) installed and
      tested offline before you fly
- [ ] Tape measure or laser rangefinder — cable runs, link distances

## Network

- [ ] More Cat6 than you calculated — the 2024 Lunsar BOM had 7 × 100 m
- [ ] RJ45 connectors, crimper, cable tester
- [ ] PoE surge arresters — one per Ethernet run, plus spares
- [ ] Spare access point and spare switch — one of each fails
- [ ] Cable ties, conduit clips, a drill if there is any chance the hospital's is elsewhere

## Power

- [ ] Surge-protected power strips — 30 in the 2024 BOM
- [ ] Universal plug adapters — 80 in the 2024 BOM; you will still run out
- [ ] Spare laptop chargers

## Server

- [ ] **A tested, bootable clone of the server** — images and a recent database dump on USB. Bonet's
      2017 contingency kit; still the best single item on this list
- [ ] OS install media
- [ ] Spare SSD
- [ ] USB-A to USB-B cable for the UPS (NUT)

## Paper

- [ ] Printed copies of every instrument form — [downloads](../4-Instruments/index.md) — power is not
      guaranteed at the desk where you fill them in
- [ ] Laminating pouches, for the "when it breaks" sheets
- [ ] A copy of this handbook, printed, in case nothing else works

## Not to bring

- [ ] Credentials written on paper
- [ ] A plan for a unit whose power and network you have not verified in the room

!!! note

    The 2024 Lunsar design noted, in its own future work, that neither installation labour nor the
    cost of wiring had been costed. Add a line for both.
