# Ada East District Hospital, Ada Foah, Ghana

**2016 · 2019–2020 · OpenMRS · Current state: unknown**

## What is known

**Summer 2016.** Two AUCOOP volunteers installed an open-source medical record system — OpenMRS,
according to the 2016 blog that cites it — at Ada East District Hospital in the Dangme East district.
The 2017 Ethiopia thesis records: *"the project worked, but the evaluation made clear the need to go
deeper into medical record systems."* It also records the intent: *"to keep improving it in order to
offer this potential to many other hospitals."*

**2019–2020.** A three-year continuation, funded by UPC's cooperation centre (2019-A032, then the
2020 call). The 2020 form describes the situation: every patient's data in notebooks stored in a room
that *"can hold up to hundreds of them"*; all workflows on paper; the hospital board had proposed
improving it; *"a software adapted for the hospital"* installed on a main server.

The plan was **phased by department**: Phase 1 outpatients — reception, vitals, family medicine,
dentistry, ophthalmology, X-ray, pharmacy, laboratory, emergency, stores — with the network already
installed and half the consulting rooms equipped; Phase 2 inpatients — surgery, burns, psychiatry —
with no network yet; Phase 3 a new paediatric wing built in 2019, to be linked by Wi-Fi.

It named a **hospital technician as counterpart**, planned that staff would *"use it themselves
without our intervention"*, and — unusually for this archive — wrote **eight verifiable indicators**:
network working, number of records registered, number of staff able to use the software, computers
working, server running, lab reports reaching consultations, paediatric-wing connectivity, and typing
speed.

The 2020 trip was scheduled for 28 July to 18 August 2020.

## What is not known

Whether the 2020 trip happened. Whether anything after 2020 happened. What the system was, exactly.
Whether it is running. The archive contains nothing after the 2020 form.

## Why it matters

Ada Foah had three things Lunsar 2026 did not: a **phased plan by department**, **verifiable
indicators**, and a **named local technician**. It also had a plan for three or four more years. Then
a pandemic, and silence. It is the clearest example in the archive of a well-designed continuation
that no mechanism existed to preserve.

!!! note "Open question"

    Find out. Contacts: the hospital technician named in the 2020 form; the 2019–2020 UPC team. If the
    system is running, it is AUCOOP's longest-lived hospital deployment and the most important case
    study it has. If it is not, it is the earliest data point in the pattern.
